# Gerenciador de tarefas

Protótipo Flask/MySQL para cadastrar usuários e tarefas.

1. Instale `requirements.txt`.
2. Execute `schema.sql` no MySQL.
3. Defina `MYSQL_PASSWORD` e, se necessário, `MYSQL_HOST`, `MYSQL_USER` e `MYSQL_DATABASE`.
4. Execute `python app.py`.

O modo de depuração só é habilitado quando `FLASK_DEBUG=true`.
