# Estudos de Kivy e KivyMD

Exercícios genéricos que estavam em `Telatest_workin`, separados dos protótipos específicos do aplicativo WorkIn.

Há exemplos de temas, botões, ícones, troca de telas, carrossel e integração experimental com Firebase. Alguns usam versões antigas de KivyMD e podem precisar de adaptação.

As configurações Firebase foram retiradas do código migrado. Copie `.env.example` para um arquivo local e exporte as variáveis antes de executar os exemplos. Não inclua chaves privadas, contas de serviço ou senhas no Git.
